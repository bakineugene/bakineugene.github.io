Применил на практике обработчик нажатия, добавив переключатель цветовых режимов для гирлянды.

В PROGMEM хранятся две формы волны: wave_hard более яркая, основной цвет wave_soft менее яркая. Используется как оттенок для смешанных режимов.

Всего добавил 9 режимов: - 3 чистых цвета - 6 комбинаций R,G,B. Один цвет основной, другой как оттенок.

    uint8_t color[3] = {0, 0, 0};
    if (mode.soft != CH_0) color[mode.soft] = pgm_read_byte(&wave_soft[idx]); // idx - индекс шага
    if (mode.hard != CH_0) color[mode.hard] = pgm_read_byte(&wave_hard[idx]);
