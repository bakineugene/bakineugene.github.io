*22:24*  
#sound

Первая идея - записать звуки в формате WAV и каким-то образом сконвертировать их в понятный для МК формат.

Записал несколько звуков - удар пальцем по столу, ложкой по кружке и голос

Форматы хранения музыки без сжатия "разбивают" аналоговую звуковую волну на "семплы".
Каждый "семпл" описывает состояние звуковой волны в определенный момент времени.
Есть два параметра, которые позволяют играться с качеством записанного звука.

1 - кол-во семплов в секунду.
8000 семплов достаточно для передачи голоса с потерей тембра.
44100 семплов достаточно чтобы воспроизвести звук неотличимо для человеческого уха (*2 от максимальной частоты которую человек может услышать)

Например удар ложечкой по чашке после пересемплирования потерял тоненькое "дзинь" и превратился почти в удар клюшкой по шайбе.

2 - размер семпла.
Определяет точность каждого семпла. Дефолт при записи - 32 бита. 

Здесь ([https://github.com/bakineugene/sounds_experiments_avr/tree/main/sounds](https://github.com/bakineugene/sounds_experiments_avr/tree/main/sounds)) звуки 8 бит, 8000 семплов в секунду
Записаны на телефон, преобразованы в Audacity ([https://www.audacityteam.org/](https://www.audacityteam.org/))
