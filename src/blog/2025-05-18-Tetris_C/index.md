Цель - сделать несложную игрушку на микроконтроллере и вспомнить C.  
В качестве первой "жертвы" выбрал "тетрис".  
Но чтобы проще было отлаживать решил для начала написать вариант для десктопа, а уже потом переписать отдельные части, чтобы выполнялось на микроконтроллере.  

Целевой "экран" будет состоять из LED матриц 8 * 8.  
Решил, что у меня будет 2 * 3 матрицы - то есть экран 16 * 24.  

## Правила

Фигуры в тетрисе называются тетрамино ([https://ru.wikipedia.org/wiki/Тетрамино](https://ru.wikipedia.org/wiki/Тетрамино))
